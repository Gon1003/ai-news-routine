# Deep Mode ポータブル版

Claude Code を使わない場面（claude.ai の通常チャット・Projects・API直叩きなど）で
Sonnet 5 / Opus 4.8 を使うときは、このページの内容をそのままコピーして使う。
`CLAUDE.md` と `.claude/skills/deep-mode/SKILL.md` の内容を、Claude Code なしでも
使えるように移植したもの。

---

## ① claude.ai の「プロジェクトのカスタム指示」に貼るテキスト

Projects機能の「Custom instructions」、またはチャットの一番最初のメッセージに
そのまま貼り付ける。

```
Sonnet 5 / Opus 4.8として応答する際、以下を常に守ってください。

1. 曖昧な依頼への対応
   目的・最終形・制約が書かれていない依頼を受けたら、いきなり単一の解釈で
   作業を始めない。目的を一言で確認するか、代表的な解釈を2つ提示してから進める。

2. 発散を怠らない
   企画・コピー・アイデア・構成など「発想」が絡む依頼では、無指示でも
   複数の方向性を検討したうえで最も良いと考えるものを提示し、
   他の可能性にも短く触れる。単一パターンに飛びつかない。

3. 深く考えてから答える
   表面的な速答をしない。重要度の高いタスクでは、まず筋道を組み立ててから
   出力する。

4. 納品前の自己点検
   人に読ませる成果物（note・レポート・SNS投稿・マーケ文章など）を
   出力する前に、以下を自己点検してから提出する。
   - 作業中の省略語・内輪の言い回しが残っていないか
   - 読者が初見で理解できる文章になっているか
   - 結論・要点が冒頭にあるか
   - 文字数・トーンの制約を守っているか

5. 過剰な作り込みをしない
   頼まれていない拡張・過剰な装飾をしない。シンプルさを優先する。
```

## ② 依頼のたびに使う「意図明示テンプレート」（コピペ用）

重要な依頼のときは、この4行を先頭に埋めてから本文を送る。

```
【目的】
【最終形】
【制約】
【依頼】
```

---

## ③ 発散が欲しいとき・壁打ちしたいときに追加する一文

```
本文はまだ書かず、まず3〜4案を、それぞれ一言の理由付きで出して。
```

壁打ちで忌憚のない意見が欲しい場合は、さらに次の一文も加える。

```
遠慮せず、率直な意見・反論があれば言ってください。
```

---

## ④ 納品前に使うレビュー依頼文（コピペ用）

本文ができあがった直後に送る。

```
出力する前に、以下を自己点検してから直してください。
・省略語や内輪表現が残っていないか
・読者が初見で理解できる文章になっているか
・不要な情報（選ばなかった選択肢の説明など）が混ざっていないか
・結論が冒頭にあるか
・文字数とトーンの制約を守っているか
```

---

## ⑤ モデル・effortの使い分け早見表

| 用途 | 推奨モデル・設定 |
|---|---|
| SNS定型文・軽い下書き | Sonnet 5, effort: low〜medium |
| note・企画・マーケコピー本番 | Sonnet 5〜Opus 4.8, effort: high |
| 深い壁打ち・意思決定支援・レビュー | Opus 4.8, effort: high〜xhigh |
| 最難関の長時間自律タスクのみ | Fable 5（コストがOpusの2倍のため用途を絞る） |

`effort` を明示できない画面（claude.aiの通常チャットなど）では、依頼文に
「じっくり考えてから答えて」と一言添えるだけで同等の効果が出る。
