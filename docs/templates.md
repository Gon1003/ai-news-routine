# 依頼テンプレート集

Claude Code でも claude.ai でも使える、コピペ用の依頼文と使い分け表。

## 重要な依頼の基本形

```
【目的】誰が、何のために使うか
【最終形】媒体・形式・分量
【制約】トーン・NG事項・締切など
【判断基準】何ができていれば「良い」か
```

全部埋まらなくてもよい。埋めた分だけ精度が上がる。

## 場面別に添える一言

| 場面 | 添える一言 |
|---|---|
| 案出し | 本文はまだ書かず、方向性の違う案を3〜4つ、狙い付きで出して。推す案も1つ教えて。 |
| 壁打ち | 同意はいらない。弱点・反論・見落としを率直に指摘して。 |
| おまかせ | 細かい判断は任せる。置いた仮定だけ最後に教えて。 |
| 調べもの | 記憶ではなく検索で確かめてから答えて。出典も付けて。 |
| 仕上げ | 出す前に、結論が冒頭にあるか・内輪の表現が残っていないか・初めて読む人に分かるか・制約を守れているかを点検して直して。 |
| 学びを残す | 今の修正は今後もずっと適用して。 |

「学びを残す」は、Claude Code では `docs/lessons.md` に記録される。claude.ai では、メモリ機能が有効ならそこに残る。無効な場合は、プロジェクトの指示に1行追記する。

## モデルと思考の深さの使い分け

| 用途 | モデル | 思考の深さ（effort） |
|---|---|---|
| SNSの定型投稿・軽い下書き・言い換え | Sonnet 5 | low〜medium |
| note・企画・コピーの本番 | Sonnet 5 または Opus 4.8 | high |
| 深い壁打ち・意思決定・レビュー | Opus 4.8 | high〜xhigh |

effort を指定できない画面（claude.ai など）では、拡張思考（Extended thinking）の設定があればオンにし、依頼文に「じっくり考えてから答えて」と添える。
